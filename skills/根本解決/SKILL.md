# 根本解決

目的を満たすために、問題を生む原因や構造に必要十分な変更を加える。

1. 目的、現状との差、守るべき制約を確認する。実装や利用状況を調べ、事実と仮説を分ける。
2. 差を生む仕組みや前提をたどる。設計判断では選択肢の利点と代償を比べ、既存設計に欠陥があると決めつけない。
3. 原因を扱う責務のある場所で、目的を満たす最小限の変更を選ぶ。必要な再設計は行うが、根拠のない抽象化や範囲拡大は避ける。
4. 具体例や適切なテストで、目的の達成と既存の必要な振る舞いを確認する。設計上の効果は、確認済みの結果と予測を区別する。

判断の根拠、変更が効く理由、検証結果と未確認点を簡潔に伝える。応急処置が必要なら、残る原因と次の対応を明示する。
